# 🎙️ Bhavya's AI Audio Lab

Real-time audio processing suite equipped with Web Audio API frequency analyzers, voice synthesizers, waveform spectrograms, and acoustic enhancements.

---

## 📂 File & Folder Structure — Direct Edit Guide

| File / Folder | What It Does | When to Edit |
| :--- | :--- | :--- |
| `index.html` | Audio canvas, equalizer sliders & recorder | Customize knobs, audio meters, and control toggles |
| `style.css` | Cyber acoustic deck styling | Modify waveform glow colors and frequency bar designs |
| `app.js` | Web Audio API node graph & FFT analysis | Adjust FFT size, filter bands, reverb, and pitch algorithms |
| `sw.js` | Offline caching service worker | Update cached assets for offline studio use |
